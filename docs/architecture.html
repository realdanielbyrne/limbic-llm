Hippoformer Architecture

A PyTorch research library of hippocampus-inspired memory modules, plus four small decoder-only language models that use them. It tests mechanisms on synthetic tasks; it is not a pretrained LLM.

Model scale
0.2–0.4 M parameters, dmodel = 64
Shared by every model
Token + position embedding, LM head, next-token loss
Tasks
One-shot recall past the attention window, continual learning
Tests
51, covering causality, memory rules and streaming state

Figure 1

Package overview

Every model takes the same input and produces logits through the same head. They differ only in how the middle of the network stores and retrieves memory.

Inside the HippocampalBlock

Strategy I maps the trisynaptic circuit onto one residual block. The block keeps the stream width d, so it drops into any transformer stack.

DGDentateGyrus
Expands 8× and keeps the top 5 % of units, so overlapping inputs get nearly orthogonal codes.
CA3CA3Autoassociative
Modern-Hopfield retrieval over the store and the current segment. Stores cue → successor pairs, so a key recalls its value.
CA2CA2Modulator
FiLM side channel driven by external or temporal context. Starts as the identity.
CA1CA1Comparator
Compares retrieved memory with the raw input from the skip path and outputs a novelty signal nt ∈ (0, 1).
SubiculumSubiculum
SwiGLU output whose gain rises with novelty, added back to the residual stream.

Scope

Included

  • Memory modules usable inside other models
  • Four small language models for controlled comparisons
  • Streaming state across calls for every memory type
  • Recall, capacity and continual-learning experiments

Not included

  • Tokenizer and pretraining data pipeline
  • Text generation loop and sampling
  • Pretrained weights
  • Fused GPU kernels or multi-GPU training

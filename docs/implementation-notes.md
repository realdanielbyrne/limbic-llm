# Implementation notes

Details and simplifications behind the limbic-llm modules.

* **Titans parallelization.** Inside each chunk, every gradient is taken against the memory state at the start of the chunk, as in the paper's mini-batch scheme. $\theta_t$ is per token, while $\eta$ and $\alpha$ are averaged per chunk, so each chunk applies one fused update. Two writes to the same key inside one chunk therefore add rather than the second overwriting the first; `memory_type="gated_delta"` avoids this with an exact per-token rule.
* **Meta-gradients.** With `meta_grad=True`, training differentiates through the memory update (second order). The gradient is taken with respect to a fresh alias of the memory, so it is the partial derivative through $M(k_t)$ only and training applies the same update as inference. Attention is written as explicit softmax because PyTorch's fused CPU kernels have no double-backward. `meta_grad=False` gives a cheaper first-order version.
* **Write scale.** The associative loss sums $\lVert M(k) - v\rVert^2$ over features, as in the paper, and each sample's fused chunk update is clipped to `max_update_norm`.
* **Causality.** Memory is read before a chunk or segment and written after it. Tests check that perturbing a token never changes logits at earlier positions.
* **CA3 writes.** Slot choice is not differentiable, but stored patterns keep their autograd graph within a call, so later recall losses train the encoding path. The store is detached between calls (truncated backpropagation through time).
* **Gated DeltaNet kernels.** `gated_delta_scan` is the reference per-token loop. `gated_delta_chunked` solves one unit-lower-triangular system per chunk, $(I+L)U = \operatorname{diag}(\beta)(V - \operatorname{diag}(\Gamma)KS_0^\top)$, gives the same result to within $10^{-4}$ (tested) and is used by default, about 12× faster on CPU. Decay ratios are computed as $\exp(g_C - g_i)$, so strong decay cannot produce 0/0. There is no fused GPU kernel; for long sequences on GPU, use a dedicated implementation such as flash-linear-attention.
* **Gated DeltaNet addressing.** `"gdn"` is standard Gated DeltaNet with q/k/v short convolutions. `"tied"` uses one address $a_t$ as the query at $t$ and as the key of the write $a_{t-1} \mapsto v_t$. `"dg"` is the same with $a_t = \text{norm}(\text{k-WTA}(W_a x_t))$.
* **Novelty supervision.** `novelty_alignment_loss` trains CA1's mismatch signal to predict the z-scored next-token loss. It is not a proper scoring rule; replacing it with log loss against an observed outcome is on the roadmap.
* **Reproducing the documents.** `python docs/src/build.py` regenerates `docs/architecture.html` from the Mermaid sources (needs mermaid-cli). `python docs/src/bib_to_json.py > docs/src/references.json && node docs/src/build_architectures_docx.js` regenerates the design document (needs the `docx` npm package and `bibtexparser`).

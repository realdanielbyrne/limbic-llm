Gated memory circuit beside a frozen model

Read from the bottom up. The frozen model is the left column. The side circuit taps it twice, keeps past states in a ring buffer, and returns recalled content to an early attention layer only when the comparator agrees.

Filter bank, per band

a_k = exp(-1 / tau_k)            tau_k in {4, 16, 64, 256, 1024} tokens
num_k[t] = a_k * num_k[t-1] + g[t-1] * x[t-1]
den_k[t] = a_k * den_k[t-1] + g[t-1]
content_k[t]  = num_k[t] / den_k[t]      what the band holds
strength_k[t] = den_k[t]                 how recently and how often it was charged
g = 1 for the fast bank; g = 1 only on gated events for the slow bank

# Round-11 RV4 additions: code review before GPU time (4 Nov 2026)

**Scope:** the code built for DEC12 (RV4 §6):
- the paraphrase and repeated-digit evaluation cells (RV4.E3, E12);
- A13, native keys (RV4.R3);
- A14, self-distillation from full attention (RV4.R1);
- A15, a teacher attention-mass target for the gate (RV4.R2.1);
- the diagnostic `diag_teacher_attention.py`.

**How it was built and reviewed:**
- Three implementers worked in isolated git worktrees, and the patches were combined in an integration worktree.
- Three adversarial reviewers each took one lens: A13 and the taps; A14/A15; the eval cells and every default path. Two independent refuters checked each finding.
- Result: 9 findings, none critical or major; 6 survived at least one refuter.

| ID | Finding | Resolution |
|---|---|---|
| R0 | Before a forward with captured K/Q, `state_report()` counts the native width as the model width (an overcount: 1.06M floats against 0.98M at Qwen3-1.7B's real 1,024-wide K/Q). The queued JSONs are unaffected (they report after side-on forwards) | Such a report is now marked `provisional` |
| R1 | A13 differs from RV4.R3's wording ("one head's K, the same head's Q at the answer position"). It uses all 8 KV heads concatenated, Q averaged over each group and over the last 8 tokens, and an uncentred cosine | Kept, and recorded as the definition of A13 in the register. Selection at initialisation is soft on the toy (read weight 0.35–0.5) because the shared frame scores every fact |
| R2 | Attention-tap hooks check that the side is on, not the window | Refuted by both verifiers (the side is never on under the full condition) |
| R3 | Native keys fall back to h without `extra` | Refuted by both (intended for unit tests and the CPU suite; an `extra` missing the layer raises) |
| R4 | `--distill-frac` with the oracle gate crashes, or reuses stale onsets on text steps | Refused |
| R5 | A14's training curve mixes KL steps and needle steps without labels | Every curve entry carries `kind` (`d` or `n`); `step_kinds` was already in the JSON |
| R6 | With both teachers off, the JSON gains `w1s_native_layer` | Refuted by both (an added default key; training identical) |
| R7 | The paraphrase task's length guard allowed the tail filler to shrink to the window or less | Refused when tail − d ≤ window |
| R8 | The golden tests do not cover every new task form | Behaviour verified unchanged separately; not changed |

**After the fixes:** the full suite gives 665 passed, 2 skipped, and the 4 known qwen35/fla failures. All new flags default off. Default outputs are byte-identical apart from three added keys from the repeated-digit split (`exact_by_repeat`, `digit1_by_repeat`, `per_sequence_repeat`).

# Round-11 Stage-A2 code: review before GPU time (5 Nov 2026)

**Scope:** the Stage-A2 code (DEC14, `research/plans/round11_combination_plan.md`):
- the gate track: hysteresis and Schmitt tests with the round-11 options, `--w1s-gate-norm init`, and `diag_gate_init.py`;
- rotary and ordinal time together, pointer replay (`--w1s-replay pointer`) and `--w1s-align-stream`;
- `run.py --init-from` and a per-sequence stale flag;
- `analyse_round.py`.

**How:** three implementers worked in worktrees and the result was integrated. Three adversarial reviewers each took one lens (gate, read, statistics), with two refuters per finding. Result: 16 findings, all standing, 6 of them major. Two fixers then worked on separate files. All changes keep defaults bitwise identical, checked on 72 module configurations and 14 end-to-end runs.

| ID | Finding | Resolution |
|---|---|---|
| Q0 | `init` removes only the offset shared across sequences; a sequence's own offset re-saturates the hysteresis and Schmitt latches (synthetic: 13–18% of sequences at c = 0.3; centred: 0%) | Docstring corrected, and a limit test added. New mode `--w1s-gate-norm seq`: the drive is centred on its own first 64 tokens, then frozen. It may share part of P50's random-filler risk, so Phase 2 runs both modes and the Phase-0 diagnostic on real states comes first |
| Q1 | At t = 0 the 1e-6 variance floor gives \|z₀\| ≈ 1000·\|d₀\| and an onset with p ≈ 1, which is never evicted at δ = 0 | Fixed under `init` (prior variance): onsets with p > 0.9 at t = 0 fall from 55–59 to 0 of 96. **The default I1 point gate has the same behaviour**: in about 50–60% of sequences a slot from position 0 is held to the end, at read weight 0.003–0.07. It was measured and left unchanged (committed recipe) |
| Q2, Q3 | The gate diagnostic was blind to the level of p and used one side seed | It now reports the median p at onsets, low- and high-p sequences and per-sequence latch saturation, over `--side-seeds 3` |
| Q4 | μ̂'s source was not recorded; it could be calibrated on an A14 text batch | The source is recorded in `state_report()["gate_norm"]`, and calibration on a batch marked `distill` is refused. `teacher.py` does not mark batches yet; A14 is not in Stage A2 |
| Q5 | `--w1s-align-stream` fell back silently to the main tap | It now raises |
| Q6 | The pointer's slot and entry choice could differ between the parallel and stream forms at exact ties | Both forms share a tie rule |
| Q7 | A time-feature list turns the linear penalty off by default | Phase-3 jobs always pass `--w1s-recency-form` explicitly |
| Q8 | The Stage-B pick read a missing Updates verdict as "not worse" | Now `unknown`, with a warning |
| Q9 | The late-drop step was noise on 10-point curves | A trailing median, with explicit statuses. Stage-A2 runs log every 50 steps. On round-10 curves, seed 4's training loss matches the learned seeds', so its failure shows only at evaluation |
| Q10 | The factorial had no resolution or alias check, and no handling of missing runs | A design check refuses resolution < III, warns at III, reports aliases, and refits on the available runs |
| Q11–Q14 | Gate-block cell sets; near-shared update rows; Newcombe for the names group; missing controls and evaluation-time modifications | Fixed |
| Q15 | s_seed pooled across seeds includes the seed main effect, so the intervals ran at about 99% | Estimated from same-seed replicates (Phase 1's I1 seed 4 and seed 4 with `--init-seed`), with the seed effect removed; a refinement of DEC14's reading rule (noted there) |
